# Deliverable Skill

Every agent deliverable must use the standard template at `.agents/guardian/templates/deliverable-template.md`.

## Mandatory sections

1. **PRE-CONDITIONS MET** — CWD, L0-L3 loaded, token valid, scope confirmed.
2. **WHAT CHANGED** — concise list of files and decisions.
3. **VERIFICATION** — commands run and their results.
4. **🎫 HANDOFF TICKET** — only if transferring to another agent.
5. **NEXT STEPS** — explicit next action or owner.

## Rules

- Do not paste full source code unless the change is one line.
- Include only relevant context; link to files instead of quoting them.
- Mark memory updates as pending for the Guardian batch update.
