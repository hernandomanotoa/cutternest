# Handoff Ticket Skill

Standard format for inter-agent handoffs. Include this in the deliverable when transferring work.

```markdown
🎫 HANDOFF TICKET:
- From: [agent name]
- To: [next agent or Guardian]
- Task: [one-line summary]
- Files touched:
  - [path]
- Decisions made: [2-3 bullets]
- Verification: [commands and results]
- Criterios de éxito cumplidos: [yes/no]
- Risks / blockers: [none | list]
- Context for next: [what the receiver needs to know]
```

Keep it compact. The receiver should be able to continue without re-exploring.
