## 2. Changes Applied

### 2.1 `frontend-agent/memory/active-tasks.md`

- **Root cause of anomaly:** file mixed active tasks with a long completed-task history.
- **Fix:** split into:
  - `active-tasks.md` — only current sprint, idle tasks, next actions, blockers (93 tokens).
  - `completed-tasks.md` — archived history (427 tokens, cold memory).

### 2.2 `knowledge-graph-agent/memory/edges.md`

- Removed redundant `contains` edges for UI composition and Docker Compose services that MCP derives via `trace_path`.
- Kept only cross-cutting relationships: agent ownership and critical-node impact table.

### 2.3 `knowledge-graph-agent/memory/queries.md`

- Split into:
  - `queries.md` — 8 hot recipes (login flow, authService impact, Redis deps, middlewares, roles, impact analysis, re-index).
  - `queries.cold.md` — 12 cold recipes + stable cache (Docker Compose separation, stack, tunnel agent, etc.).
- Agents load hot recipes by default; cold recipes are loaded on demand.

### 2.4 Stubs in `knowledge-graph-agent/memory/graph/`

- Recapped 15 overweight stubs to ≤50 tokens each by shortening `Responsibility` and removing optional `Related decisions` sections.
- Added `scripts/audit-stub-tokens.mjs` to continuously enforce the <50 token budget.

### 2.5 DevHive templates / profile

- Added `knowledge_graph.queries_cold` and `agent.completed_tasks_path` to `.devhive/profile.yaml`.
- Updated `knowledge-graph-agent-skill.md.hbs` scope to include `queries.cold.md`.
- Re-rendered all agent SKILL files and passed `validate-devhive`.

## 4. Recommendations

1. **Apply the active/completed split to all agents** (`backend-agent`, `auth-agent`, `test-agent`, etc.) so their `active-tasks.md` files stay under ~100 tokens.
2. **Gate cold memory at the Guardian level** so agents only load `queries.cold.md` or `completed-tasks.md` when explicitly authorized.
3. **Run `audit-stub-tokens.mjs` in CI** after any `knowledge-graph-agent` update to prevent stub inflation.
4. **Consider adding a `memory/token-budget.md` manifest** documenting per-file token caps and owner.
