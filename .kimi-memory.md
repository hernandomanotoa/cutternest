## Decisiones clave

- SQLAlchemy 2.0 sincrono con SQLite para simplificar MVP.
- TOTP secret cifrado con Fernet derivado de JWT_SECRET_KEY.
- Refresh tokens hasheados con bcrypt; rotación en refresh.
- Archivos exportados servidos desde `/exports` via StaticFiles y nginx proxy.
- La ruta de SQLite en Docker es `sqlite:///data/cutternest.db` (relativa al workdir `/app`), persistida via volumen `./data:/app/data`.
- El backend aplica migraciones automáticas (`_migrate_schema` en `main.py`) para añadir columnas/tablas faltantes y normalizar enums obsoletos.
- **Nueva decisión (2026-08-19)**: crear un Assembly Planner vanilla offline en `frontend/public/assembly-planner/` como complemento al ensamblaje React existente.
- **Nueva decisión (2026-08-19)**: refactor progresivo de UI React con componentes base reutilizables (`frontend/src/components/ui/`) y Zustand para estado global.
- **Nueva decisión (2026-08-21)**: arquitectura de capas en el Assembly Planner (`core`, `utils`, `services`, `components`, `views`) y centralización de config, ver ADR-0014.
- **Nueva decisión (2026-08-21)**: posicionamiento vertical de repisas/zapatero por nombre y zona, ver ADR-0015.
- **Nueva decisión (2026-08-21)**: estantes regulables se apilan consecutivamente desde la base o desde el último zapatero con un solo gap configurable (`shelfMiddleGap`), ver ADR-0017.
- **Nueva decisión (2026-10-13)**: passwords con `bcrypt` puro en `backend/app/security.py` (sin passlib; `crypt` queda en desuso desde Python 3.13). Bundle inicial del frontend minimizado: `manualChunks` con vendor estático (react/zustand) + `Assembly3DV2` lazy — three.js y charts solo bajo demanda (−82 % carga inicial).
- **Nueva decisión (2026-10-27) — sistema gola**: apertura sin tiradores por módulo en el Assembly Planner (`js/services/golaService.js`, servicio puro). Evolución importante traída por pull (commits `7e027b9`..`7fc4c34`): ya NO son tiras simples sino **canales de melamina** por gap — canal C = `m{mod}gola-c{i}-fondo` (panel vertical retranqueado) + `-pestana-sup`/`-pestana-inf` (forman el canal de agarre abierto al frente); canal L = `m{mod}gola-l{N}-fondo` + `-pestana` (agarre desde arriba; la caja del cajón superior se rebaja para pasar bajo el perfil). Física: gap entre frentes = `golaPaso`(3) + `golaPerfilHeight`(50) + `golaPaso` (el agarre lo genera el retranqueo, no aire vertical; `golaFingerClearance` solo aplica a la L). Valores centralizados en `GOLA_PERFIL_TALLER` (`core/config.js`, fuente 'taller-medido'), editables global y por módulo (`cn-assembly-gola-cfg`, merge defaults ← global ← módulo; persisten en versiones locales como `golaModuleCfgs`). Extras: `drawerFrontLuz` configurable (luz perimetral, spec gola 3), foco gola en 3D (oculta cajones completos), validador consciente del gola (exención de rango ergonómico; el canal L queda tapado por el frente a propósito), tour de onboarding (`components/tour/driver.js` + `data/golaTour.js`), autoguardado con recuperación (`cn-assembly-autosave`, debounce 2 s en `app.js:initAutosave`), migración de metas gola en `moveModule`. Suites en verde: 972 unit + 118 DOM, ejemplos 0/0.
